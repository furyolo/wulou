# 无漏 AI 当前专题教师版 PDF 下载

油猴脚本项目，无构建步骤、无外部依赖。适用于 Chrome / Edge 的 Tampermonkey。

## 安装与使用

1. 在 Tampermonkey 中新建脚本，将 `wulou-teacher-pdf-downloader.user.js` 的完整内容粘贴进去并保存。
2. 登录无漏 AI，打开“福建中考分类汇编2：基础大题（2027版）”，进入任一具体考点或考法的学习页面，刷新页面。
3. 页面右侧默认仅显示小型 `‹ PDF` 入口。点击展开面板，查看当前专题及子项数量，再点击“选择文件夹并下载”。
4. 在浏览器文件夹选择框中选择 `D:\Coding\wulou\local-materials\中考数学分类汇编` 并允许写入。请选择根文件夹，不要选择它下面的专题文件夹。
5. 脚本自动创建或使用当前专题文件夹，以 3 路有限并发下载全部子项的教师版 PDF。

```text
默认：[‹ PDF]       展开后：
                   +------------------------------+
                   | 教师版 PDF               [›] |
                   | 专题6：反比例函数            |
                   | 10 个子项 · 3 路并发归档      |
                   | [选择文件夹并下载]           |
                   | > 下载记录                   |
                   +------------------------------+
```

“二级目录”按照本项目约定指学习目录最外层的“专题6：反比例函数”等专题或题型。其下 6.1、6.3 等小节全部纳入范围，不再创建小节文件夹。例如：

```text
中考数学分类汇编/
└─ 专题6：反比例函数/
   ├─ 考点1-概念-考法3-…(老师版).pdf
   └─ …(老师版).pdf
```

## 行为与限制

- 只在 `/user-center/course-wrong-learn/*` 学习页生效；讲义封面页不显示按钮。
- 使用当前登录权限，收集当前专题全部学习子项，再逐项读取学习页的教师版按钮；不依赖侧栏 PDF 图标或目录是否展开。数量表示待检查的学习子项数，未提供教师版按钮的项目会记录失败原因。
- 只下载教师版，不下载学生版或 PPT。先检查 `%PDF-` 文件头再写入。
- 保留服务器文件名并修复中文响应头编码；同名文件追加 `(2)` 等编号，不覆盖旧文件。重复运行会另存一份，不按内容去重。
- 默认同时处理 3 个子项；学习页与 PDF 网络请求并行，文件名分配和磁盘写入串行，继续保证同名文件不被覆盖。
- 单项完整流程最多等待 120 秒；单项失败记录后继续。遇到 HTTP 429、502、503、504 最多尝试 3 次，优先遵循服务器的 `Retry-After`，否则等待 1 秒、2 秒后重试。
- 停止会同时取消所有正在进行的网络请求和重试等待；已保存文件保留，尚未开始的项目不再处理。下载期间请不要跳转或关闭页面。
- 文件夹由浏览器选择和授权，脚本不能静默写入硬编码的磁盘路径。刷新后再次选择，浏览器通常会记住上次位置。
- 若网站改变目录结构、权限或下载参数，脚本会提示错误；不会猜测并扩大下载范围。

## 1.2.0 并发下载

- 下载队列默认使用 3 个工作协程；不再在每个项目后固定等待 800 ms。
- 网络请求并发执行，文件名检查和写盘保持串行，避免并发任务争用同名文件。
- 某个项目失败不会中断其他项目；面板实时显示已完成、下载中和等待中的数量。
- HTTP 429、502、503、504 支持有限重试；停止按钮会取消全部活动请求和重试等待。
